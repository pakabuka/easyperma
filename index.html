Details

Find your key in Perma settings. Folders and subfolders load when you paste your key. Use Refresh to reload them, or choose “Enter a folder ID manually.”

Files stay in your browser. URLs are sent to Perma. Pending capture statuses refresh automatically every 10 seconds; content checks are disabled.

Before creating links, the app searches archives accessible through your API key across all folders. Exact source URLs are matched, ignoring fragments. Successful captures are preferred; pending captures are reused to avoid duplicates. If lookup fails, creation stops so duplicates are not generated blindly.

Perma links are included as soon as the API returns their IDs. Automatic status refreshes flag failures reported later. Refreshes run in the background without blocking exports or verifying page content.

Existing Perma links are kept as supplied and excluded from creation. Word export adds returned links beside their original footnote URLs as URL [https://perma.cc/XXXX-XXXX]. URLs without a returned Perma link stay unchanged.

If a submission response is lost, use Find unconfirmed links to look for its existing archive without submitting a duplicate.
