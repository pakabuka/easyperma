Details

Find your key in Perma settings. Folders load when you leave the key field; you can also enter a folder ID.

Files stay in your browser. Only extracted URLs are sent to Perma. No API key is saved.

Content checks inspect the archive where the browser allows access and flag common error pages. They cannot prove that an archive supports a citation. Blocked or unreadable pages are marked “Needs review.”

Capture statuses follow the Perma API. Pending captures can be checked again with the same main button, without creating new links.
