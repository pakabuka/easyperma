Details

Find your key in Perma settings. Folders and subfolders load when you paste your key. Use Refresh to reload them, or choose “Enter a folder ID manually.”

Files stay in your browser. Only extracted URLs are sent to Perma. No API key is saved.

Red flags identify failed captures, suspected bot checks, access-denied pages, and missing content. Content checks inspect saved HTML, never the live source. Unreadable archives get an amber “Needs review” badge; review them before export. An API success alone does not verify the source content. Manual review decisions are included in Excel.

Capture statuses follow the Perma API. Pending captures can be checked again without creating new links. Create an individual link using its row button.
